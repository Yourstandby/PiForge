# Pi Agent Desktop v0.8.4

**English** · [简体中文](./v0.8.4.zh-CN.md)

Released: 2026-08-28

## Added

- **Drag-and-drop file upload**: dropping any file into the chat window inserts it as an `@path` mention, so the agent can read that file directly (#18)

## Fixed

- **Provider API key persistence**: an API key saved in the `Models` dialog was previously written only into an in-memory override (discarded with the temporary runtime of each request) and never landed in `auth.json`, so a newly configured provider permanently showed "not configured" and never appeared in the list. It now goes through the SDK's `login(api_key)` persistence path, is visible immediately after saving and survives a restart; Disconnect correspondingly deletes the stored credential for real (#21)
- **Installer directory-page hint**: when the NSIS installer switches drives (C→D) the path box showed only the drive root, easily making users think the default folder was lost and type a path by hand (which can nest directories). The directory page now shows a bilingual hint at the top explaining that the `Pi Agent Desktop` subfolder is created automatically (#19)
- **Build fix**: `build/installer.nsh` gains a UTF-8 BOM. Without one, makensis parses the include using the system ANSI code page, and the em-dashes in the file trigger a `Bad text encoding` compile failure on zh-CN/GBK machines

## Compatibility and known limitations

- The Windows x64 installer is not code-signed, so the first run may trigger a SmartScreen prompt.
- Providers authenticated only through environment variables (such as GitHub Copilot) do not support saving an API key in the dialog; an explicit error is returned when you try.
