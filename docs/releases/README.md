# Release notes

**English** · [简体中文](./README.zh-CN.md)

Every PiForge release has a note here in two languages: the English file is the default (`vX.Y.Z.md`) and the Chinese one is kept alongside it (`vX.Y.Z.zh-CN.md`). For the item-by-item record — "what changed / did any default change / how to use the switches" — see [CHANGELOG.md](../../CHANGELOG.md); to download a build, see [Releases](https://github.com/Yourstandby/PiForge/releases).

`tag CI` means the release date is whenever the tag's CI build produced the installers; those notes state it that way instead of naming a day.

## Conventions

- Only `.md` files are release notes; `.zh-CN.md` are their Chinese counterparts. Adding a release means adding both files plus a row above.
- Notes for versions before v0.8.0 exist only in the repository's git history.
