# PiForge v0.8.2

发布日期：以 tag `v0.8.2` 构建产出为准（Windows NSIS + ZIP，Linux deb，macOS universal）。

## 本版主题：让成本可见 · 让子 Agent 真能干活 · 让长会话不卡

### 1. 上下文可视化：从"感觉快满了"到"看得见"

- 新增 `agent-host/context-budget.ts`（纯函数）：把用量换算成**相对硬顶**的比例与等级（观察 60% / 临界 85% / 越顶），前端只负责上色。
- 对话底栏新增 14px 环形指示器：环走满 = 贴到硬顶，变红 = 已越顶并脉冲；精确数字收进 tooltip 与 `aria-label`，压缩进行中环会转。
- 硬顶常量单一来源仍是 `agent-host/compaction-plan.ts`，展示层不另立阈值。

### 2. 子 Agent：授权、超时、休眠一次收口

- 新增 `agent-host/tool-grants.ts`：默认**继承**父 Agent 的 `activeTools`，`bash / read / write / edit` 运行时存在即强制保留；父 Agent 显式 `tools: [...]` 时取并集放宽；递归与 UI 副作用工具（`spawn_agent`、`herdr_*`、`orchestrator_*`、受管进程、浏览器）永不下放；请求了运行时没有的工具立刻抛 `PERMISSION_MISSING`，第一轮就讲清楚，不允许空转到熔断。
- 授权只读 `pi.getAllTools()` 全量注册表，绝不读工具存根目录：存根开启不影响提权，子 Agent 的工具集也不会回写父 Agent 的声明，前缀缓存保持字节级稳定。
- 舰队单轮超时默认 **5 分钟**（原 15 分钟），可被调用方覆盖并夹在 1s–30min，到点 `abort` + 强制终止，不留 zombie。
- 空闲 **5 分钟自动休眠**（60s 扫一次）：`MAX_FLEET=4` 的槽位不再被挂机会话吃掉；`herdr_spawn` 支持"完成即退出"的一次性任务。

### 3. 输出风格：只砍水分，不砍推理

- 新增 `agent-host/prompts/output-style.ts`：**纯静态常量、禁止任何动态插值**（prompt 缓存按前缀命中，混进时间戳/路径就整段失效）。先要求深入思考，最终输出禁客套、禁复述问题、改代码只给 diff、非明确要求不展开长文。
- `agent-host/desktop-output-style-extension.ts` 以幂等方式并入 system prompt（已有则跳过）。

### 4. 长会话不再卡：三个 Worker + 两处缓存 + 一次清理

- `lib/jsonl-worker.ts`：>1MB 会话文件整体进 `worker_threads`（源码内联，standalone 不用多带文件），失败/超时一律回落内联解析。
- `lib/git-status-worker.ts`：`git rev-parse` + `git status` 进 worker（20s 超时），主线程只做 cwd 相对路径换算。
- `lib/session-scan-worker.ts`：会话索引扫描与分页同理，首屏不等扫盘。
- `lib/transcript-turn-cache.ts`：轮次对象按「消息引用同一 **且** 工具结果引用同一」缓存，流式期间不再每帧全量重渲（修掉 `turn 173 rendered 777 times`）。
- `lib/chat-scroll-memory.ts`：`display:none` 下量不出高度时沿用最后已知滚动位置，切回标签不再跳回第一条消息。
- `lib/session-scope.ts` + `hooks/useSessionScope.ts`：挂在会话上的 `setInterval` / `ResizeObserver` / `setTimeout`（对账、贴底滚动、自动标题、乐观刷新）全部登记，切会话或关标签一次性 `disposeSession()`。

### 5. 会话列表分页

- 首屏 **20 条**，滚动到底每次追加 **10 条**；索引 TTL 10s，扫描并发 8、`SessionInfo` 读取并发 4、缓存上限 400。
- 刷新按已加载深度重取（`loadedDepthRef`），修掉"项目分组消失又出现"的跳动。
- 空闲预取下一批（并发 1、2s 超时）；行内标记"已在标签页打开"；一轮任务结束只补一次列表刷新（1.2s 节流）。

### 6. 技能面板

- 技能带 `scope: global | project` 与来源 `agents | pi | package | other`，项目级 `.pi/skills` 与用户级 `~/.agents/skills` 分开呈现。
- 修掉 Git Bash / msys2 下 `HOME=/c/Users/x` 导致 Windows 拼出的目录不存在、用户级技能整批丢失的问题（调用期间对齐真实家目录，带串行锁）。
- 关键词自动分类（设计 / 前端 / 后端 / 测试 / 文档 / 发布 / 工作流 / 元技能 / 其它）+ 一句话概述；手动分类存 `localStorage`，不污染 `SKILL.md`；扫描结果 5s 缓存。

### 7. 图片

- 贴图先在本地缩到视觉模型 **1568px** 长边上限（`createImageBitmap` + `OffscreenCanvas` 走合成线程）：模型看到的信息一致，上传体积与计费 token 降 4~10 倍；任一环节不可用即回退原始读取。
- 缩放注记只给模型看，渲染前剥除，用户不会再看到自己"没说过的话"。
- 对话与工具输出里的图片点开即灯箱：缩放 / 平移 / 旋转 / 下载 / 复制 / 翻页，键盘 `+ - R`。

### 8. 回执、归属与状态栏

- **任务结束卡片**：只有"忙 → 空闲"这一跳才算跑完，附最后一条回复摘要（1200 字符截断）；后台标签保留绿点直到切回。
- **Agents 归属**：右侧面板按 `项目 › 会话` 分组，排序 `session > project > other`，运行中置顶；数据全走既有 SSE（`subagents` / `fleet`），零轮询。
- **状态栏让位**：引擎健康点与 pi 核心版本迁入标题栏「系统状态」弹层（弹层不打开就不查上游版本）；额度/余额改为右侧固定宽度区，数字变化不再拉宽整行；金额按 3 位有效数字显示（`0.001034` 不再被降级成 `<0.0001`）。

## 兼容性与已知限制

- Windows x64 安装包未代码签名，首次运行可能触发 SmartScreen 提示。
- 子 Agent 工具授权默认放宽到核心写工具（`bash/read/write/edit`），安全检查从"只读洁癖"改为"父 Agent 显式收窄"；编排与 UI 副作用工具仍严格不下放。
- 3 项跳过测试为平台条件跳过，非功能缺陷。
