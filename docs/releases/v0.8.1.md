# PiForge v0.8.1

**English** · [简体中文](./v0.8.1.zh-CN.md)

Released: per the build output of tag `v0.8.1` (Windows NSIS + ZIP, Linux deb, macOS universal).

## Theme of this release: transparency for multiple agents · a manual fleet · a savings valve for tokens

### 1. Agents panel synced in real time

- A new global `fleet` event topic (host broadcast + `/api/fleet/events` SSE); the Agents panel consumes both the `subagents` and `fleet` streams and no longer depends on polling.
- Fixing "the main conversation is already running an agent but the right panel is empty": `spawn_agent` / `herdr_spawn` were hidden as tool stubs, so the model could not call them at all. Both are now **permanently declared** alongside `tool_search` / `desktop_use_tool`.
- Running entries are pinned to the top of the list, with entries spawned by this session first; only when the SSE drops does it degrade to polling, and the panel says so.

### 2. Manually stationing persistent fleet agents

- The panel gains "+ new / load agent": name, system prompt, read-only tool permissions (read/grep/find/ls), or import from a JSON configuration (single object / array / `{profiles:[]}`).
- Configurations persist to `<agentDir>/fleet/agents.json` (atomic write, a bad file degrades to empty, one broken entry does not affect the others), and are shown again after a restart.
- Waking only creates a session and does not run a first turn (no tokens burned); messages can be sent from inside the card (backed by `herdr_message`), and "temporary sub-agent / fleet agent" are distinguished.
- New RPCs: `fleet.list / save / delete / import / wake / message`.

### 3. Agent savings valve (hard gate)

In `agent-host/agent-guards.ts`, shared by the `subagents` and `herdr` runners:

| Valve | Threshold | Behavior |
| --- | --- | --- |
| Turn limit | 3 turns | The 4th turn is rejected outright with a hint to summarize and create a new agent |
| Forced summary | 1,200 characters | Only the conclusion plus key points go back to the main agent; raw output stays in the panel |
| Context fuse | 10k tokens / turn | Interrupted immediately and marked as fused, after which new instructions are rejected |

### 4. Other

- README rewritten: the three architectural boundaries, a multi-agent comparison, token economics with measured savings, commands and the release flow.
- The terminal no longer force-follows output by default (it follows only while the user stays at the bottom).
- Status-bar tool badge colors refined; the startup page switches to the new logo.

## Compatibility and known limitations

- The Windows x64 installer is not code-signed, so the first run may trigger a SmartScreen prompt.
- `electron/process-tree.test.ts` occasionally times out under full concurrency and passes when run alone (sensitive to system load, not a functional defect).
- Fleet agents are still limited to read-only tools; writing files or running commands goes to the main agent or an orchestrator worker.
