# PiForge v0.8.1

发布日期：以 tag `v0.8.1` 构建产出为准（Windows NSIS + ZIP，Linux deb，macOS universal）。

## 本版主题：多 Agent 透明化 · 手动舰队 · Token 省钱阀门

### 1. Agents 面板实时同步

- 新增 `fleet` 全局事件主题（Host 广播 + `/api/fleet/events` SSE），Agents 面板同时消费 `subagents` 与 `fleet` 两条流，不再依赖轮询。
- 修复「主对话已经在跑 Agent，右侧面板却是空的」：`spawn_agent` / `herdr_spawn` 曾因工具存根被隐藏，模型根本调不到。现在两者与 `tool_search` / `desktop_use_tool` 一起**常驻声明**。
- 列表运行中置顶、本会话派生的优先；SSE 断线才降级为轮询，并在面板上明示。

### 2. 手动派驻常驻舰队 Agent

- 面板新增「+ 新建 / 加载 Agent」：名称、System Prompt、只读工具权限（read/grep/find/ls），或从 JSON 配置导入（单条 / 数组 / `{profiles:[]}`）。
- 配置持久化到 `<agentDir>/fleet/agents.json`（原子写、坏文件降级为空、单条损坏不影响其它），重启自动回显。
- 唤醒只建会话、不跑首轮（不烧 token）；卡片内可直接下发消息（底层 `herdr_message`），并区分「临时子 Agent / 舰队 Agent」。
- 新增 RPC：`fleet.list / save / delete / import / wake / message`。

### 3. Agent 省钱阀门（硬闸）

`agent-host/agent-guards.ts`，`subagents` 与 `herdr` 两个 runner 共用：

| 阀门 | 阈值 | 行为 |
| --- | --- | --- |
| 轮数上限 | 3 轮 | 第 4 轮直接拒绝，提示汇总后新建 Agent |
| 强制摘要 | 1200 字符 | 回给主 Agent 只有结论 + 关键要点，原始输出留在面板 |
| 上下文熔断 | 10k tokens / 轮 | 立刻中断并标记熔断，之后拒绝新指令 |

### 4. 其它

- README 重写：架构三条边界、多 Agent 对照、Token 经济与实测节省数据、命令与发布流程。
- 终端默认不再强制跟随滚动（仅在用户停留在底部时跟随）。
- 状态栏工具徽章配色细化；启动页切换新版 logo。

## 兼容性与已知限制

- Windows x64 安装包未代码签名，首次运行可能触发 SmartScreen 提示。
- `electron/process-tree.test.ts` 在全量并发下偶发超时，单独运行可通过（系统负载敏感，非功能缺陷）。
- 舰队 Agent 仍限定只读工具；写文件/跑命令请交给主 Agent 或编排 Worker。
