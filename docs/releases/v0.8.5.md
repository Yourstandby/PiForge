# Pi Agent Desktop v0.8.5

**English** · [简体中文](./v0.8.5.zh-CN.md)

Released: 2026-09-01

## Added

- **Linux desktop package**: `electron-builder` gains an x64 `deb` target, producing `Pi-Agent-Desktop-X.Y.Z-linux-amd64.deb` with a matching `latest-linux.yml` (#24)
- **macOS Universal enters the official release channel**: Intel + Apple Silicon DMG / ZIP are built by Actions on tag (the first three-platform release after #22 landed)
- **Desktop packages GitHub Actions**: pushing a `vX.Y.Z` tag makes `.github/workflows/desktop-packages.yml` package on Windows / Ubuntu / macOS runners and upload to the same GitHub Release; a manual `workflow_dispatch` only produces artifacts (#25)
- **Bilingual UI**: user-visible copy goes through `lib/i18n` (`en` / `zh-CN`, with a `system` preference) (#22)

## Fixed

- **Long-term memory was nearly useless for Chinese**: FTS5 switches to `trigram` with a LIKE fallback for short queries; CJK near-duplicates use Dice 0.5 supersede; kana / Hangul are covered, and two CJK texts sharing Latin words are not misjudged as duplicates (#23)
- **Renderer white screen**: a global error boundary with a bounded automatic reload after a render crash (#20)

## Compatibility and known limitations

- The Windows / macOS / Linux installers are all unsigned. SmartScreen may appear on Windows, Gatekeeper on macOS, and Linux auto-update installs the unsigned `.deb` through `dpkg`/`apt`, which needs root authorization. A Release must carry all of `latest.yml` / `latest-mac.yml` / `latest-linux.yml`; omitting one means that platform receives no updates.
- A mixed Chinese-English short query (such as `压缩 sqlite`) may go through LIKE instead of FTS ranking; on the CJK side only Han / kana / Hangul bigrams are compared, and Latin words do not participate in Dice.
- Providers authenticated only through environment variables (such as GitHub Copilot) do not support saving an API key in the dialog.

## Verification

- CI for the version PR: `lint · typecheck · test`, `test (windows)`, `test (macOS)`, `build (next.js)`
- After the tag, the `Desktop packages` workflow builds all three platforms and uploads this Release; after publishing, the asset names and sizes on this page are checked against the version / SHA512 of the three `latest*.yml` files
