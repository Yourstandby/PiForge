# v0.11.2 — 会话按时间分桶

侧栏会话改成按时间收纳：今天 / 昨天 / 过去 7 天按天，12 个月内按自然月，更早按自然年。
折叠头上的数字就是点开后的真实条数，点开不会空——因为它来自同一份已经加载到内存的数据。

## 改动

- 首屏一次取满 200 条（服务端单次上限），分页不再驱动滚动加载。
- 重写时间分桶：取消「更早」垃圾桶，月 / 年维度可读。
- 计数只数根会话，分支子会话不重复计。
- 默认只展开今天 / 昨天；其余桶收起，点开是纯状态变更。
- 删掉自动加载暂停、滚动哨兵、每项目「显示全部」。

## 已知边界

- 首屏冷启动约 400ms（200 条会话元数据首次解析），缓存命中后 23ms。
- 会话总数超过一页时，底部「加载更早的会话」不带数字：服务端 `total` 含临时会话，数字会是假的。
