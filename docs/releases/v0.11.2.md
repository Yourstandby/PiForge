# v0.11.2 — sessions bucketed by time

**English** · [简体中文](./v0.11.2.zh-CN.md)

Sidebar sessions are now filed by time: today / yesterday / the past 7 days by day, within 12 months by calendar month, older by calendar year. The number on a collapsed header is the real count you get when you open it, and opening it is never empty — because it comes from the same data already loaded in memory.

## Changes

- The first screen fetches 200 at once (the server-side single-request cap), and pagination no longer drives scroll loading.
- Time bucketing rewritten: the "older" bin is gone, and the month / year dimensions are readable.
- Counts count root sessions only; branch sub-sessions are not counted twice.
- Only today / yesterday expand by default; the other buckets are collapsed, and expanding is a pure state change.
- Auto-load pausing, the scroll sentinel and the per-project "show all" are removed.

## Known boundaries

- First-screen cold start is about 400ms (parsing metadata for 200 sessions the first time), 23ms once the cache is warm.
- When the total exceeds one page, "load older sessions" at the bottom carries no number: the server's `total` includes temporary sessions, so the number would be fake.
