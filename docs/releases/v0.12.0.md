# PiForge v0.12.0 — projects belong to the user · numbers and switches tell the truth

**English** · [简体中文](./v0.12.0.zh-CN.md)

Released: 2026-11-04

This release ships v0.11.3 and v0.11.4, which were never published separately (the previous public version was v0.11.2), plus a new development guard and a full rewrite of the README and release notes.

## Highlights

### Projects belong to you

Hover the `⋯` at the end of a project row in the left column, or right-click → "rename project" / "remove from sidebar".

- Only the displayed name and visibility in the left column change; the directory on disk and session ownership stay put;
- Only one local preference is written (`pi-sidebar-projects-v1`), no session is deleted and no directory is touched;
- Later, choosing the same directory again with "new project" restores it automatically; an empty name or the original folder name restores the default.

### Usage tells the truth first

- Cost reports only accumulated real `usage`, with the streaming-stage estimate removed: no `usage` received, no number shown.
- Live usage is isolated per session; another session running no longer adds to the current usage strip.
- Abbreviation above one thousand: exact integers below 1000, one decimal at or above (`2.9K` / `69.8K`), carrying to `1.0M` at ≥ 999,950.
- Streaming events are coalesced per frame, the tool-card stopwatch tick is localized, and re-renders from typing / switching sessions / switching panels are pruned.

### Injection switches state their defaults first

- **AGENTS.md / CLAUDE.md injection**: three-state control (follow global / on / off), settable both globally and per project, on by default.
- **HANDOFF.md continuation injection**: a HANDOFF.md at the project root or under `docs/` can be injected into the system prompt, off by default.
- **Compaction summary**: always Chinese, more concise, and by default only takes over the summary body.

### A watchdog that understands long jobs

- The stall threshold goes 20s → **90s** by default, and 90s is the floor (a smaller runtime value is clamped); the ceiling stays 10min.
- Dropdown presets become 90 / 120 / 300 / 600 seconds; the scan period stays 5s with two consecutive over-threshold scans to escalate, so by default it goes red after about 100s without meaningful progress.
- Still **zero tokens, zero prompt injection**: it only watches for meaningful progress in the program layer.

### Pi core 1.5.0

- The three `@earendil-works/pi-*` packages are pinned to exactly `1.5.0` (transitive dependencies gain `pi-schema`).
- Upstream tool argument validation now runs in `pi-schema`; every PiForge tool is a plain JSON Schema, so the only adaptation is the MCP `clientRegistration` type widening to `"auto" | "dcr" | "cimd"`.

### Developer experience

- `dev:electron` gains a pre-flight guard: when `out/` is older than the sources it fails and points at `npm run build:static`, instead of letting you debug against a stale UI for half a day. `PIFORGE_SKIP_STATIC_FRESHNESS=1` downgrades it to a warning.
- The call budget moves from "count" to "batches": 1 for simple / 2–3 for ordinary / 3–4 for research, at most 12 parallel per batch; at the ceiling, deliver a verifiable conclusion first and leave the rest of the todo for the next round.

## Default behavior changes (must read before upgrading)

| Item | v0.11.2 | v0.12.0 |
| --- | --- | --- |
| Watchdog stall threshold | 20s default, 5s minimum | 90s default, 90s minimum (presets 90/120/300/600s) |
| Thinking level for new sessions | low | medium (balanced) |
| Clicking window close | hides silently | asks "minimize to tray / quit", rememberable |
| Project name / visibility | fixed | renameable, removable from the sidebar |
| Usage display | includes a streaming estimate | real usage only; abbreviated above one thousand |
| Context file injection | always on | can be turned off (on by default), global + project three-state |
| HANDOFF.md injection | none | opt-in, off by default |

Unchanged: the three-process boundary, zero internal ports, authorize-before-IO for files, codemode defaulting to `only`, themes and the three-column layout.

## Install and compatibility

- Installers are built by CI: Windows NSIS (plus ZIP), macOS Universal DMG + ZIP, Linux `.deb`, each with a packaged startup smoke on its platform.
- **The Windows installer is not code-signed** and may trigger SmartScreen.
- **The macOS installer is unsigned and notarized neither**, so the first launch may trigger Gatekeeper.
- **The Linux `.deb` has no debsig**: auto-update installs it through `dpkg -i` / `apt --allow-unauthenticated`, which needs root authorization; download integrity is verified by the SHA512 in `latest-linux.yml`, and omitting that file means no auto-updates.
- Auto-update uses the existing electron-updater chain (check → confirm → download → restart to install), with the update source fixed at build time.
- Running alongside the terminal CLI still shares `~/.pi/agent`; concurrent writes to the same session from both ends are still unsupported.
