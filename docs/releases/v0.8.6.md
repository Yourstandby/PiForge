# Pi Agent Desktop v0.8.6

**English** · [简体中文](./v0.8.6.zh-CN.md)

Released: 2026-09-06

## Added

- **Git Worktree Clone**: a session Clone can create an independent worktree and new branch outside the source Git repository; it fails closed when the target, branch or worktree identity cannot be proven (#37)

## Improved

- **Code quality tightened**: dead code and the AgentMemory stub backend are gone; API errors / fetch fallbacks / the modal shell / outside-click listeners converge into a single helper (#41)
- **Worktree cleanup hardened**: ownership and rollback paths are verified by filesystem identity, so worktrees not created by this app are not deleted by mistake

## Compatibility and known limitations

- Hand-editing `desktop-settings.json` to set `ltm.backend` to `agentmemory` no longer works; long-term memory is SQLite (enabled) or Noop (disabled) only. If you need the old REST stub: `git show fd5bca1 -- lib/ltm/agentmemory-backend.ts`.
- The Windows / macOS / Linux installers are all unsigned. SmartScreen may appear on Windows, Gatekeeper on macOS, and Linux auto-update installs the unsigned `.deb` through `dpkg`/`apt`, which needs root authorization. A Release must carry all of `latest.yml` / `latest-mac.yml` / `latest-linux.yml`; omitting one means that platform receives no updates.
- Providers authenticated only through environment variables (such as GitHub Copilot) do not support saving an API key in the dialog.

## Verification

- CI for the version PR: `lint · typecheck · test`, `test (windows)`, `test (macOS)`, `build (next.js)`
- After the tag, the `Desktop packages` workflow builds all three platforms and uploads this Release; after publishing, the asset names and sizes on this page are checked against the version / SHA512 of the three `latest*.yml` files
