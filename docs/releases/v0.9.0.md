# PiForge v0.9.0

发布日期：以 tag `v0.9.0` 构建产出为准（Windows NSIS + ZIP，Linux deb，macOS universal）。

## 本版主题：卡住看得见，介入点一下

v0.9.0 新增**无进展看门狗（Watchdog）与人工介入**：监控完全在程序层（内存状态机 + 定时器），
不产生任何 LLM 请求，也不往 system prompt / 对话历史里写任何字节。任务卡住时右侧「系统监控」
面板亮灯，你可以点一下 **Skip（强制跳过）**、发一句 **极简询问**（禁止跑工具、限 20 字），
或发起 **深度诊断**。所有介入指令都走既有的 steer / 排队 / prompt 通路，没有新增的模型直连。

配套：用量条常驻输入框下方；窄窗口（≤1080px）侧栏改为浮层；图片灯箱的复制/大图显示修好。

本版同时首次发出 v0.8.3 的省钱改造（工具 23 → 12、按需工具域、结果去重、缓存保活）；
v0.8.3 未单独发布。

## 新增

- **无进展看门狗**：默认开启，20s 无有效进展判疑似卡顿（连续 3 次扫描升级 `stalled`，
  单工具超阈当次升级），退避提醒 30s / 60s / 120s，之后标 `failed`（只标界面，不干预模型）。
  两把尺子：`lastActivityAt`（成功且不重复的动作 / 正文增量）与 `lastLivenessAt`（活的迹象）；
  并发按 `toolCallId` 逐个建档。
- **人工介入（HITL）**：`Skip` / `极简询问`（默认）/ `深度诊断`；Host 侧守卫：同动作冷却 3s、
  单任务上限 5 次、无活跃任务直接拒绝。
- **右侧「系统监控」面板**：心跳、逐工具计时、疑似阻塞点、退避通知、JSON 详情、停滞阈值热切换
  （15/30/60/90 秒，只写内存）；会话列表 / 标签栏 / 工具卡三处只读状态灯。
- **用量条**：Token、缓存命中、上下文占用、上游额度常驻输入框下方，点开仍是「用量与额度」弹窗。
- **窄视口浮层侧栏**：视口 ≤ 1080px 时左右栏变浮层并默认收起，聊天区独占宽度。

## 变更

- 上游额度只请求一次（输入框用量条拉取，底栏复用同一份快照）。
- 思考档位菜单 3 → 4 档（`auto` / `high` / `medium` / `low`），不再按模型能力过滤；
  不支持的档位由后端收敛，老会话持久化值仍正常回显。
- 会话状态灯优先级：看门狗红（停滞）> 运行中蓝 > 等待操作琥珀 > 后台完成绿。

## 修复

- 图片灯箱「复制」此前永远失败：`clipboard.write` 只接受 `image/png`，现在先重绘成 PNG。
- 灯箱优先显示原图（`previewUrl`），不再用发给模型的降采样图（长边 1568）当大图。
- 灯箱右键菜单 `Esc` 先关菜单；工具栏在 Electron 窗口拖拽条下让位。

## 迁移与升级

- **无强制迁移动作**，默认前缀、工具声明、命中率均未变。
- 想完全回到 v0.8.2 行为：`PIFORGE_WATCHDOG=0`（不建定时器、不记状态、`watchdog.status`
  只回 `{enabled:false}`）＋ `PIFORGE_ON_DEMAND_DOMAINS=0`（全部工具常驻，前缀 6 988）。
- 按需工具域优先级不变：环境变量 `PIFORGE_ON_DEMAND_DOMAINS` > 设置项 `onDemandDomains` >
  默认 `shell`；`=1` 仍是 `memory` + `orchestrator` 按需的历史别名，不是「全按需」。
- **升级方式**：Windows 直接运行 `PiForge-Setup-0.9.0.exe`（覆盖安装，会话与设置在 `~/.pi` 与
  应用数据目录中保留）；或解压 ZIP 免安装使用。macOS / Linux 见 Release 资产。
- **不在本版**：工作区中未提交的自动更新（`electron/app-update*`、`useAppUpdater`、
  `AppUpdateRow`）与流式合帧（`hooks/agent-session/frame-coalescer.ts`）仍是 WIP，未进入 v0.9.0。

- `npm run smoke:prefix-budget` 退出码 0：默认 6 240 tok / 11 工具 / 核心 710，3 轮 cacheRead 命中 99.5%。
  前缀与环境有关：`~/.agents/skills` 存在时 `<skills>` 段进 system prompt（本机 +1 598 字符 ≈ +400 tok，
  即 6 640），属环境差异；基线取清空技能目录后的口径。
- `npm run smoke:agent-host`：含 `watchdog.status`（默认阈值 20s）、`watchdog.task`、
  `agent.intervene`（非法 action 与会话不存在都必须拒绝）三类断言。
- `npm test` 1 253 项：1 248 通过、3 项按平台跳过。失败 2 项位于**未跟踪的 WIP 测试文件**
  （`electron/auto-update-controller.test.ts` 的 import 少 `.ts` 后缀、`lib/agent-host-client.test.ts`
  等待尚未实现的握手重试），不属于本版内容。

## 兼容性与已知限制

- 安装包未代码签名：Windows 可能出现 SmartScreen 提示，macOS 可能出现 Gatekeeper 提示。
- 看门狗是**观测与人工介入**，不做自动处置：自动跳过 / 自动杀进程仍在路线图上（见 README）。
- 介入指令会进入对话历史（那是你自己的指令），看门狗自动通知不会（只留在界面队列里）。
- 与终端 CLI 同时运行仍共享 `~/.pi/agent`；同一 session 两端同时写入仍不受支持。
