# Pi Agent Desktop v0.8.0

**English** · [简体中文](./v0.8.0.zh-CN.md)

Released: 2026-08-25

## Highlights

- Redesigned desktop workspace: a more compact toolbar, message input area, and Apple-style material layering.
- New liquid thinking orb: WebGPU first, automatic Canvas fallback, and it respects the reduced-motion setting.
- New reorderable follow-up queue: press Enter while the agent runs to steer immediately, Alt+Enter to queue; reorder with drag, buttons, or Alt+arrow keys.
- Steer messages show a pending-delivery state and align with session messages once the server confirms.

## Runtime and dependencies

- Pi SDK: `@earendil-works/pi-ai` / `pi-coding-agent` `0.84.3`.
- Next.js / eslint-config-next: `16.3.2`.
- electron-updater: `6.8.9`; electron-builder: `26.15.3`; @electron/packager: `20.3.0`.
- Fixed npm dependency vulnerabilities that could be upgraded safely; Electron stays at `36.9.5` to avoid introducing a desktop runtime regression across 8 major versions in this release.

## Compatibility and known limitations

- The Windows x64 installer is not code-signed, so the first run may trigger a SmartScreen prompt.
- `@lobehub/icons`'s transitive dependencies still produce a peer warning for React 19; the current deep import of brand SVGs passes type checking and tests.
- A full `npm audit` still reports 2 high-severity findings for Electron 36 and its `extract-zip`; upgrading to Electron 44 will be handled as a separate task.
- Next.js 16.3 is still compatible with the current `middleware.ts` but suggests migrating to `proxy.ts` in the future.

## Verification

- Web and Electron TypeScript type checks pass.
- Unit tests, lint and the Electron updater dependency check pass.
- The Next.js dev-mode health check returns 200 and a malicious Origin request returns 403.
- The Windows NSIS installer is rebuilt by `npm run dist` before release, with artifact metadata verified.
