# Pi Agent Desktop v0.8.3

**English** · [简体中文](./v0.8.3.zh-CN.md)

Released: 2026-08-26

## Added

- **Full built-in provider selection**: all 39 `MODELS.generated` providers of `pi-ai@0.84.3` are visible in the `Models` dialog, with icons added for the 9 missing ones (`ant-ling / baseten / nvidia / opencode / qwen-token-plan×3 / xiaomi / zai-coding-cn`) via `@lobehub/icons`, bringing `PROVIDER_ICONS` to 39 mappings
- **Complete API key list**: `GET /api/auth/all-providers` now sources truth from `runtime.getProviders()`, so `openrouter-images` and friends are no longer hidden by `registry.getAll()`'s zero-model filtering, and the `AddProviderPicker` grid automatically shows unconfigured providers
- **Custom templates**: the single `OpenAI / Anthropic compatible` card in `AddProviderPicker` splits into 4 templates: `OpenAI Compatible (openai-completions)` / `Anthropic Compatible (anthropic-messages)` / `OpenAI Responses (openai-responses)` / `Google Generative AI (google-generative-ai)`, searchable and filterable by `label/api/custom`, with `ModelsConfig.addCustomProvider(api)` persisting according to the chosen `api`

## Fixed

- The three `qwen-token-plan` variants and `zai-coding-cn` used to render as blank entries without icons and now show the `Qwen/ZAI` icons correctly

## Compatibility and known limitations

- The Windows x64 installer is not code-signed, so the first run may trigger a SmartScreen prompt.
- `@lobehub/icons`'s transitive dependencies may still produce a peer warning for React 19.
- The security audit results for Electron 43.4.1 and its transitive dependencies will be handled separately in a future Electron major upgrade.
