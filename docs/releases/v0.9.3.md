# PiForge v0.9.3

发布日期：以 tag `v0.9.3` 的 CI 产出为准（Windows NSIS + ZIP，Linux deb，macOS universal）。

## 本版主题：把「已经发生的事」显示出来

0.9.2 之后没有架构改动，九条改动全部围绕同一件事——**界面上看到的东西必须和系统里真实发生的一致**：

- 模型在长时间思考时，界面只显示一行「思考中…」，内容要等思考结束才出现；
- 长会话压缩过之后重开，压缩前的提问从界面上消失（实测本机某个会话 77 条提问只显示 7 条）；
- 打包版收到大图，一律变成 `[Image omitted: could not be resized ...]` 的占位符；
- 对话正在跑时点开一个文件，右栏不展开、或者展开后把会话卡住；
- 看门狗介入后，模型把「你卡在哪个工具」当成新提问，答完就结束本轮；
- 深色界面缺失——白天长时间用浅色，夜里没有可切换的方案。

## 新增

- **夜晚模式**（`lib/theme.ts` + `components/ThemeBoot.tsx` + `app/globals.css`）
  常规设置新增三选一：跟随系统 / 浅色 / 深色。偏好写 `localStorage["pi-theme"]`，
  `app/layout.tsx` 的内联脚本在 React 之前落一次 `data-theme`（首屏无闪烁），
  挂载后再校正并监听 `prefers-color-scheme`。`globals.css` 新增
  `:root[data-theme="dark"]` 令牌组（`--color-*` 与旧 `--bg/--text` 两套并行），
  历史组件里写死的浅色字面量由 `scripts/gen-dark-remap.mjs` 生成的映射表兜底。
- **思考边流边看 + 每段思考紧跟其工具调用**（`components/Transcript.tsx`、
  `components/transcript-process.ts`）`RoundProcess` 从「思考数组 + 工具数组」两个平行数组
  改为按时间排序的 `groups[]`（一段思考 + 其后 0..N 个工具）。思考中自动展开、容器内自动跟底、
  正文只渲染尾部 2400 字；开始输出正文时自动收起。纯渲染层改动，不回传模型，token 成本 0。
- **消息时间**：提问 / 思考 / 回答的左下角显示 `HH:MM`（跨天补 `M/D`），老数据无 `timestamp`
  时整块不渲染。
- **worktree worker 的合并回主干命令**：`orchestrator_status` 附带 `mergeBackHint`——
  `log` / `diff --stat` 两条只读命令、`merge --no-ff` 一条写操作，路径含空格自动加引号。
  只给命令不代跑，是否 squash、冲突怎么处理交给人。

## 修复

- **压缩前的历史不再消失**（`lib/session-reader.ts`）：`buildSessionContext` 之前走
  `buildSessionProjection()`（给模型看的投影，只保留最新 compaction 之后的条目），
  改为沿 `parentId` 链取全量；compaction 只投影成一条 custom 标记（不进提问刻度），
  压缩前那段做瘦身（长文本/思考截预览、图片换占位）。最坏会话 payload 25 MB → 3 MB，
  中位数不变；`entryIds` 与 `messages` 仍一一对应，Fork / 回溯对齐不变。
- **打包版不再把超限图片吃掉**：bundle 是 ESM，内联的 SDK `photon_rs.js` 用 `__dirname`
  读 `photon_rs_bg.wasm`，bundle 里 `__dirname` 未定义且 wasm 没被复制 → `loadPhoton()`
  恒为 `null` → 任何需要缩放/编码的图片直接返回占位符。banner 补 `__dirname`、
  `runtimeAssets` 复制 `photon_rs_bg.wasm` 到 bundle 旁。6000×3000 PNG：修前 `ok:false`，
  修后 `ok:true`（2000×1000）。
- **对话进行中点开文件不卡会话**：打开文件/差异一律展开右栏；大文件（>80 KB 文本）
  不再走 Prism 同步高亮（会占满主线程，流式回复与输入框一起卡死），降级为纯文本行渲染并
  截断到 4000 行；Agent 自动揭示不再抢走用户正在看的视图。
- **看门狗介入后继续原任务**：抽出 `CONTINUE_AFTER_INTERVENTION`，`skip` / `ask` /
  `ask_brief` 三种指令共用「答完立刻继续、不结束本轮、不做收尾总结」；卡顿判定
  10 s × 3 → 5 s × 2（约 25 s 亮红灯），任务还在跑也允许人工喊停。
- **`content` 为 string 的消息不再击穿 ErrorBoundary**：文本提取统一进
  `lib/message-content.ts`，三处手写分支合并成一次调用。

## 产物

本版本地只出**免安装**目录（`npm run pack` → `release/win-unpacked/PiForge.exe`，直接双击运行，
不注册安装信息）。安装包 / deb / dmg 由 `desktop-packages.yml` 在 push `v0.9.3` tag 后于 CI 构建，
本地不再重复构建，避免两套产物口径。

## 迁移与升级

- 从 0.9.2 升级无需迁移动作；会话与设置分别在 `~/.pi` 与 `%APPDATA%\piforge`。
- 夜晚模式默认「跟随系统」，老用户首次启动看到的仍是原来的浅色霜蓝（系统为浅色时）。
- 免安装版直接替换 `win-unpacked` 目录即可；安装版按 Release 资产的 `PiForge-Setup-0.9.3.exe` 覆盖安装。
